# Energy Grid Optimization

A Quantum Impact project investigating quantum subroutines for day-ahead energy market optimization using SPP historical market offers.

The current classical model is a continuous, energy-only, single-node auction. It retains signed offers and purchase bids and integrates block/sloped marginal-price curves. Full-day validation covers July 1, 2026 under two disclosed historical fixed-demand scenarios. It is not SPP operational SCUC/SCED or nodal pricing: SPP-only price MAE against historical SPP MEC is $20.56/MWh.

Every inferred data interpretation or modeling assumption must be recorded in [ASSUMPTIONS.md](ASSUMPTIONS.md) before use.

## Data and licensing

Datasets come from **[SPP.org](https://www.spp.org/)** and are publicly accessible through the [SPP portal](https://portal.spp.org/pages/historical-offers).

| File in `data/` | Contents |
| --- | --- |
| `DA-ENERGY-OFFERS-202607010100.csv` | Energy offer/bid MW and price curves |
| `DA-OR-OFFERS-202607010100.csv` | Operating reserve offer prices and regulation fields; audited, not optimized |
| `DA-MC-202607010100.csv` | Historical clearing quantities, fixed demand and SMP by BAA |
| `DA-LMP-SL-202607010100.csv` | Historical settlement-location LMP and its energy/congestion/loss components |
| `DA-BC-202607010100.csv` | Historical binding constraints; diagnostics, not a network input model |

The files cover 24 operating-day hours. Official specifications and provenance are in `data/reference/`; [provenance.json](data/reference/provenance.json) retains reference and historical-result download URLs and hashes.

Git includes the five input CSVs and source provenance. Generated `results/`, environments, caches, logs, and downloaded reference archives/extractions stay local through `.gitignore`. Result links in the findings refer to local artifacts, which can be regenerated by running the study.

## Python reading order

1. [offer_audit.py](offer_audit.py): optional introduction to the input columns, curves, signed MW, repeated codes and reserve-data limitations. It inspects data and does not optimize.
2. [fidelity_validation.py](fidelity_validation.py), `main()`: follow one hour from historical fixed-demand selection through curve loading, solving, verification, price comparison and award export. Historical prices are comparison outputs and never enter a solve.
3. [energy_auction.py](energy_auction.py): the optimization engine. Read `load_curves()` and `Curve` first; then `solve()` and `_solve_numerical()`; then `clearing_oracle()` and `verify()`. `run()` and the CLI provide a separate single-hour entry point.
4. [audit_fidelity_artifacts.py](audit_fidelity_artifacts.py): reloads published awards and source files to rebuild certificates, verify provenance and recompute metrics.
5. [test_energy_auction.py](test_energy_auction.py) and [test_fidelity_regression.py](test_fidelity_regression.py): hand-solvable examples, signed consumption, fixed demand, fallback handling and the numerical convergence regression.

The physical interpretation is: mandatory fixed demand stays fixed, while the solver chooses supply and responsive purchase quantities to minimize integrated offer cost minus bid value. Signed net supply must equal fixed demand. The balance constraint's dual gives the simplified marginal price.

## Run

From this project folder in PowerShell, create the local environment if needed:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --cache-dir .pip-cache -r requirements-local-lock.txt
```

Verify and run the full-day study:

On a fresh clone, download the public guide archive used for report provenance first (downloaded copies remain ignored):

```powershell
Invoke-WebRequest -Uri 'https://spp.org/Documents/75871/SPP%20Markets%20Public%20Data%20Guide%20and%20Samples%20v36%201.zip' -OutFile 'data/reference/SPP_Public_Data_Guide_v36.zip'
```

```powershell
.\.venv\Scripts\python.exe -m unittest test_energy_auction test_fidelity_regression -v
.\.venv\Scripts\python.exe fidelity_validation.py
```

Audit the retained completed study:

```powershell
.\.venv\Scripts\python.exe audit_fidelity_artifacts.py results/fidelity-20261010T202700Z-faa1a381
```

New studies create separate folders in `results/`; pass the printed folder to the audit. The retained result set contains its manifest, full report, hourly prices, all submission awards and rebuilt artifact audit.

For one historical-demand hour:

```powershell
.\.venv\Scripts\python.exe energy_auction.py --hour '07/01/2026 01:00:00' --fixed-demand-mw 37492.254 --full-hour-only
```

Calling `energy_auction.py` without fixed demand runs a separate zero-extra-fixed-demand auction, not the historical-demand case. `--full-hour-only` avoids the smaller block-only subset, which cannot supply the main historical obligation.
